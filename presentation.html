GridWise: Smart Campus Energy Optimization

0:00 – 0:35

⚡ The Problem & Context

Campus microgrids must navigate complex operational real-time conditions:

  • Dynamic Hourly Tariffs: Shifting electricity prices from 5 to 32 BDT/kWh.
  • Solar Photovoltaic Fluctuations: Variable 24-hour generation curves.
  • Physical Battery Dynamics: Strict charge/discharge rate caps, round-trip energy balance, and end-of-day neutrality ($E_{23} = E_{\text{initial}}$).

🎯 Core Objective

Build an automated, headless HTTP REST API service that:

  • Interprets: 1–3 unstructured natural-language operator notes using an LLM.
  • Guardrails: Sanitizes output deterministically with zero hallucinations.
  • Optimizes: Minimizes 24-hour total grid cost using Linear Programming in < 4ms.
  • Conforms: Strictly adheres to the official JSON schema and $\le 5.0\text{s}$ P95 latency.

🛡️ Untrusted AI Design Pattern

LLM output is treated as untrusted user input. Guardrails strip phantom fields, normalize intervals (e.g. 1 PM to 3 PM $\rightarrow$ [13, 14]), and enforce global versus windowed constraints.

⚡ Mathematical Soundness

Optimization is decoupled from LLM text generation. The Linear Program guarantees globally optimal cost with zero cycling penalties and strict end-of-day battery neutrality.

Slide 3 of 5 · Robustness

Directive Coverage, Safety & Infeasibility

1:15 – 1:55

📋 Complete 6-Directive Compliance

  • solar_reduction: Usable factor ($0 \le \text{factor} \le 1$) during window.
  • minimum_battery_reserve: Supports both time-windows and global full-day reserve without hours.
  • no_charge_window / no_discharge_window: Battery rate forced to 0.
  • max_grid_window: Grid import capped at $X\text{ kWh}$.
  • no_op: Irrelevant distractors (cafeteria, sports) safely ignored with null adjustments.

⏱️ P95 Latency & Failure Safeguards

  • 3.8s LLM Timeout: Guarantees response time never breaches the competition's $\le 5.0\text{s}$ P95 rubric limit (full 3/3 points).
  • Zero 500 Crashes: Graceful fallback to regex semantic engine under cloud provider throttling.
  • Physical Infeasibility Handling: Mathematically impossible grid caps return clean HTTP 400 Bad Request.
  • Secret Safety: Zero API keys or tokens committed or exposed in responses.
